Software Engineering

VacciCare — Kids Vaccination Portal

A secure MERN-based enterprise software package aimed at streamlining pediatric immunizations.

System Architecture

Built using a modular client-server framework. React serves as the decoupled single-page application (SPA), connecting via REST endpoints to an Express/Node backend backed by a MongoDB document cluster.

[ React SPA Frontend ] <--- HTTP/JWT ---> [ Express.js REST API ]
                                                |
                                      +---------+---------+
                                      |                   |
                               [ MongoDB Cloud ]  [ Nodemailer/Twilio ]
                                (Patient Data)     (SMS/Email Alerts)

Key Engineering Elements

1. Dynamic Scheduling Engine: Uses date algorithms to automatically map correct immunisation dates based on the infant's birthdate, calculating gaps and safety buffers.

2. PDF Generation: Renders custom layouts dynamically on the backend using pdfkit and exports a clean, print-friendly file containing cryptographic verification tags.

3. Authentication: Sessions are secured using signed HTTP-Only JsonWebTokens (JWT) with configurable expiry limits.

Sample Code Block: Token Middleware

const jwt = require('jsonwebtoken');

const authenticateToken = (req, res, next) => {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1];
  
  if (!token) return res.status(401).json({ error: 'Access denied. No token provided.' });

  jwt.verify(token, process.env.JWT_SECRET_KEY, (err, user) => {
    if (err) return res.status(403).json({ error: 'Token is invalid or expired.' });
    req.user = user;
    next();
  });
};

AI & Machine Learning

Course RAG Assistant — Retrieval-Augmented Generation

An end-to-end RAG pipeline turning course videos into a question-answering assistant grounded in the transcript content.

System Architecture

Course video audio is transcribed with OpenAI Whisper into timestamped chunks, embedded using the Gemini API, and stored in a pandas DataFrame. At query time, the question is embedded with the same model, compared against every chunk via cosine similarity, and the top-matching chunks are passed to an LLM to generate a grounded answer.

[ Whisper Transcription ] ---> [ Timestamped JSON Chunks ]
                                        |
                              [ Gemini Embeddings ]
                                        |
                    [ Cosine Similarity Retrieval (Top-K) ]
                                        |
                       [ Gemini LLM + Guardrailed Prompt ]
                                        |
                         [ Streamlit Chat Interface ]

Key Engineering Elements

1. Semantic Retrieval: Every transcript chunk and every user question are embedded into the same vector space, allowing questions to match relevant content even when phrased differently than the source text.

2. Hallucination Guardrails: A similarity threshold filters out clearly unrelated questions before calling the LLM, and a strict prompt instruction forces an explicit "not covered" response instead of speculative answers on topically-adjacent but non-answering content.

3. Source Transparency: Each answer links back to the exact video title and timestamp it was generated from, so responses are auditable rather than a black box.

Sample Code Block: Retrieval Logic

def retrieve(query: str, df: pd.DataFrame, top_k: int = 3):
    query_embedding = create_embedding(query)
    similarities = df["embedding"].apply(
        lambda emb: cosine_similarity(query_embedding, emb)
    )
    results = df.copy()
    results["similarity"] = similarities
    return results.sort_values("similarity", ascending=False).head(top_k)
